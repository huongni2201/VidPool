# 00 — Project Principles

## Product

VidPool is desktop-first, single-user, and local-first.

## Principles

- canonical project state stays local
- provider/model engines are replaceable
- AI output is structured and validated
- actual aligned audio drives timing
- users can override and lock AI output
- long-running work is durable
- infrastructure stays minimal
- every concept has one source of truth
- architecture should be reversible at external boundaries

## YAGNI

Do not add distributed infrastructure for hypothetical future scale.

## Human Authority

AI proposes. The user approves, edits, locks, or regenerates.
